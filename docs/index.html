Perguntas frequentes

Quais arquivos o Jim converte?

PDF com texto selecionável, Word no formato .docx e arquivos TXT.

E se o PDF for escaneado?

Não funciona. Um PDF escaneado é só imagem, sem texto para extrair. O formato antigo .doc também não é suportado.

A leitura em voz alta envia áudio para algum servidor?

Não. A leitura usa a voz do próprio navegador de quem lê. Nenhum áudio sai do computador.

Onde ficam os documentos convertidos?

No banco de dados do seu próprio site, como um tipo de conteúdo do WordPress. Cada documento aparece em Documentos, já com o shortcode.

Quanto tempo leva uma conversão?

Depende do tamanho do arquivo. Um livro inteiro pode levar até cerca de um minuto.

Como instalo?

Baixe ou clone o repositório em wp-content/plugins/jim-conversor-acessivel/, rode composer install --no-dev para instalar as dependências e ative o plugin em Plugins › Plugins instalados.

Como recebo atualizações?

O plugin está em submissão ao diretório oficial do WordPress. Depois de aprovado, as atualizações chegam pela tela de Plugins. Até lá, cada versão é publicada no GitHub.

Posso usar em projetos comerciais?

Sim. O Jim é software livre sob a GPL v2 ou posterior: você pode usar, estudar, modificar e redistribuir, inclusive comercialmente, mantendo a mesma licença.
