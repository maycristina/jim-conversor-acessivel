Основные возможности

  • 1

    Автоматическая конвертация

    Автоматическое преобразование документов (PDF, текст…) в удобные для просмотра веб-страницы.

  • 2

    Встроенное чтение вслух

    Преобразование текста в речь с помощью API браузера.

  • 3

    Настраиваемое чтение

    Регулируемый размер текста, темы и высокая контрастность.

  • 4

    Автоматическое оглавление

    Создаётся прямо из заголовков документа и закладок (bookmarks) PDF.

  • 5

    Маркер и Lightbox

    Отмечайте важные фрагменты и увеличивайте изображения документа.

  • 6

    Автоматическое SEO

    Заголовок, описание и структурированные данные для каждой опубликованной страницы.

  • 7

    ИИ-наставник по желанию

    Позволяет читателям задавать вопросы по документу.

  • 8

    Поддержка 7 языков

    Португальский, испанский, французский, немецкий, русский, китайский и хинди.

  • 9

    Пакетная конвертация

    Отправляйте сразу несколько документов TXT или Markdown.

По желанию: ассистент для вопросов по документу.

По умолчанию выключен

Читатель может открыть на странице окно чата и задать вопрос по этому документу — текстом или голосом. Ответы появляются постепенно, по мере создания.

Вы решаете, будет ли он существовать, где появится и как будет себя вести: имя, характер, инструкции и приветственное сообщение. Чтобы включить, достаточно добавить собственный ключ API.

  • OpenRouter
  • Claude
  • OpenAI
  • Gemini
  • DeepSeek

Ключ хранится в вашем WordPress в зашифрованном виде, у использования есть лимиты в час и в сутки, а панель показывает журнал происходящего.

Доступен на семи языках.

Исходный код Jim написан на английском, а плагин включает переводы на язык вашего сайта или пользователя. Страница чтения, панель и руководство говорят на языке тех, кто ими пользуется.

  • Portuguêspt-BR
  • Español
  • Français
  • 中文简体
  • हिन्दी
  • Русский
  • Deutsch

Озвучивание использует голоса, которые уже предлагает браузер читателя, а текст читается на языке самого документа.

Переводы хранятся в панели проверки в WordPress, чтобы тот, кто публикует, мог проверить каждый текст.

Для кого

Jim — инструмент для сообществ, которые публикуют.

Неважно, к какому сообществу вы относитесь:

  • шахматы
  • образование
  • философия
  • наука
  • религия
  • журналистика
  • литература
  • коллекционирование
  • исследования
  • или любая другая тема

Jim создан, чтобы сделать этот процесс проще для тех, кто публикует, и гибче для тех, кто читает.

Как это работает

Jim автоматизирует часть работы, которую обычно выполняют вручную. Он превращает файлы в HTML-содержимое, готовое к публикации:

  • PDFPDF с выделяемым текстом
  • .docxДокументы Word
  • .mdMarkdown
  • .txtПростой текст

Файлы TXT и Markdown можно отправлять пакетом — до 20 небольших файлов за раз.

Вместо

  1. получить
  2. открыть
  3. скопировать
  4. отформатировать
  5. проверить
  6. опубликовать

Процесс может быть таким

  1. отправить
  2. конвертировать
  3. опубликовать
  4. [documento_acessivel id="123"]

У каждого документа есть свой шорткод.

У читателя есть элементы управления, чтобы настроить чтение под себя:

  • Читать
  • Слушать
  • Перемещаться

Легко и просто.

Цель — сделать публикацию объёмных материалов быстрой и обеспечить пользователям удобное чтение онлайн, избавив от необходимости скачивать файлы или пользоваться внешними конвертерами.
