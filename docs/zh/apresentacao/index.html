尊重服务器的工程

一个90万字的作品 或很多20份报告 不需要停止你的住宿:

短步顺序队列 :PHP内存定义了每个PDF的上限(约42 MB和256 MB).
明确限制 :每个文件从1到100 MB(默认为10 MB),每个文件最多300个图像(默认为100).
没有外部程序 :转换时使用插件中包含的 PHP 库。
上传已检查为真 :实际内容类型 (finfo), clean name, 单个后缀和文件夹, 以 Apache 和 LiteSpeed 的方式阻断脚本的执行 。
扫描的 PDF, 不奇怪 :没有可选择的文本(和没有OCR),Jim在发布空页前警告.
7种语言:葡萄牙语、西班牙语、法语、德语、俄语、中文和印地语。 在设置中,按钮会引导到每种语言的文件,以审查和贡献.

你管理我的公寓吗? 它不需要外部程序,PDF天花板遵循服务器内存.

扫描PDF有用吗? 没有 Jim不做OCR,他在发布空页前警告.
